## Decisions needed before layout

1. **RF path (J3 / W1) — blocks the board edge plan.** The module is the ESP32-C6-MINI-1U (U.FL port, no on-board antenna). As drawn, a U.FL → SMA-plug pigtail (W1) runs to J3, an SMA edge connector whose RF pin is not connected — so the pigtail's plug would occupy J3 and leave no port for the antenna. Options:
   - **a. (recommended)** Delete J3 from the board; use a U.FL → SMA-jack **bulkhead** pigtail mounted through the enclosure wall. No RF copper on the PCB at all.
   - b. Keep J3 on a board edge and add a U.FL receptacle beside it with a short 50 Ω coplanar trace to J3's centre pin; a U.FL–U.FL jumper links the module to it.
   - c. Swap to the ESP32-C6-MINI-1 (PCB antenna) and give it the antenna keep-out at a board edge — only if the enclosure is RF-transparent.
2. **BT1 battery holder.** The schematic uses the Keystone 1042 land (KiCad standard footprint). The genuine Keystone 1042 is not on LCSC (customer-supplied or hand-fitted). The LCSC holder MYOUNG BH-18650-B1BA002 (C2988620) does **not** fit that land (its pads are 82.6 mm apart vs 79.4 mm) — choosing it means drawing its footprint first.
3. **Sourcing risks** (LCSC stock on 2026-11-28): Q6 FS8205A TSSOP-8 — 0; J4–J7 Phoenix MC 1,5/3-G-3,5 — 5 (four per board); L_SOLAR — 22. Decide whether to source them globally or substitute *before* layout if a substitute changes the land pattern.
4. **GDT1/GDT2** are DNF footprints (Littelfuse GTCS23 land). Keep them for site-specific fitting, or delete the two symbols if surge arresters will never be fitted.

Choices made in the 2026-11-28 pass that are easy to revisit: SW1/SW2 C&K KSC641JLFS (IP67, J-lead; the gull-wing KSC6xxG was out of stock); L1 Vishay IFSC1515AHER4R7M01 (fits the existing footprint, Isat ≈2 A); U1 in SOT-89 (the package LCSC stocks for the Holtek part); J4–J7/J12 as Phoenix MC 1,5 pluggable headers (the BOM's long-standing choice; the schematic had fixed PT 1,5 screw terminals).

Known firmware gap, not a layout blocker: channel 2 (J5, AIN1) is fully wired but the firmware reads only channel 1.

## Layout procedure (KiCad 10)

1. **Open and check.** Open `welld.kicad_pro`; let KiCad 10 re-save the sheets. Run **ERC**. Expected, waivable: "input pin not driven" on passive-driven analog inputs (ADS1115 AINx, FB pins) and style warnings on generated label placement. Anything else is a finding — fix it in the schematic, re-run `netlist_check.py` and `footprint_check.py`. (Optional: install the Espressif library from KiCad's Plugin and Content Manager to get the module's 3D model.)
2. **Board setup** (PCB editor → Board Setup), before importing: 2 layers, 1.6 mm FR-4, 1 oz. Design rules inside any standard 2-layer process: 0.2 mm track / 0.2 mm clearance for signals, vias 0.3 mm drill / 0.6 mm pad. Net classes: **Power** (VBAT, VBAT_RAW, BATT_N, VUSB, VUSB_IN, VSOLAR, VSOLAR_IN, SOLAR_SW, SOLAR_FW, CN_CS, VLOOP, VLOOP_SW, VLOOP_L, GND) ≥ 0.5 mm; **Loop** (VLOOP_CH2, LOOP_PWR_CH1/2, LIM_E_CH1/2) ≥ 0.4 mm; default 0.2 mm.
3. **Import.** Tools → Update PCB from Schematic (F8): expect 163 footprints and no errors (no missing footprints, no unmatched pins — that is what `footprint_check.py` guarantees).
4. **Starting spread.** Tools → Scripting Console, paste `kicad_place_script.py`. Positions are rough starting points around a ≈100 × 60 mm board.
5. **Place** by the groups in `placement_constraints.md`: battery carrier band along one long edge, field connectors along the opposite long edge, USB-C on a short edge; the boost hot loop, the solar buck hot loop, the ADS1115 analog island ≥ 20 mm from the boost, the TP4056 thermal pour, the loop limiters with ≥ 1 cm² collector copper.
6. **Outline.** Draw Edge.Cuts around the finished placement. Add mounting holes (e.g. 4 × `MountingHole:MountingHole_3.2mm_M3`) at positions agreed with the enclosure, and fiducials if the assembler asks for them.
7. **Route** power first (short, wide; the hot loops in `placement_constraints.md`), then the Kelvin sense pair to R19, then signals. GND pour on both layers with via stitching; no pour under L1 or L_SOLAR.
8. **DRC**, then outputs per `fab_checklist.md` (Gerbers + drill, BOM and placement files with DNP parts excluded).

Re-run `netlist_check.py` and `footprint_check.py` after KiCad first re-saves the sheets (to confirm nothing moved) and after any schematic edit during layout.
